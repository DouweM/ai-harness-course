Coder, taken apart

The Harness's Coder is a coding agent built from capabilities on this page: FileSystem, Shell, RepoContext, SubAgents and ClearToolResults, plus its instructions, output limits and argument repair. Pick the same pieces yourself and you get a different agent. A reviewer that reads the code and runs the tests but never writes a file:

code/part2/ch6_capabilities.py, a reviewer from Coder's pieces
from pydantic_ai.capabilities import LocalWorkspace
from pydantic_ai_harness.filesystem import FileSystem
from pydantic_ai_harness.repo_context import RepoContext
from pydantic_ai_harness.shell import Shell

reviewer = Agent(  # Coder's pieces, chosen yourself: reads code, runs tests, writes nothing
    'anthropic:claude-sonnet-5-5',
    instructions='Review the change in this repository. Run the tests. Do not edit files.',
    capabilities=[
        LocalWorkspace('.'),
        FileSystem(read_only=True),
        Shell(allowed_commands=['git', 'pytest']),
        RepoContext(),
        ClearToolResults(max_fraction=0.7, placeholder='[Cleared to save space. Read the file again if you need it.]'),
    ],
)
