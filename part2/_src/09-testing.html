Testing

The model's judgment is Part 3's job. Everything around it is ordinary code, and every idea in this part gets a test that runs in a second, offline.

A cheap adversary for your gates

The point: harness ideas are deterministic and testable without a model. TestModel calls every tool; the approval gate either holds or it doesn't.

Saturday 21 NovBefore the agent runs unattended over the weekend, the team wants proof that nothing writes to the ledger without a person, whatever the model does.

TestModel is a stand-in model that calls every tool it's offered, with arguments generated from their schemas, then answers. It doesn't judge anything; it pokes everything.

One test per idea

Every chapter's idea is a property of your code, so each gets a test. FunctionModel lets a test play the model: look at what the request offered, answer badly on purpose, check what comes back. Set ALLOW_MODEL_REQUESTS = False once, and any test that would reach a real model fails instead.
